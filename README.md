# Portfolio

اپ اندروید Flutter با رابط فارسی و RTL برای مشاهدهٔ دارایی مفید، تفکیک موجودی بین سبدهای محلی، دیده‌بان، قیمت‌های عمومی TGJU و خروجی Markdown.

## آنچه در این نسخه پیاده شده است

- معماری feature-first با `data / domain / presentation`، مدیریت state با Cubit، خروجی Repositoryها با `Future<Either<Failure, T>>` و DI با `get_it + injectable`.
- ورود خواندنی مفید با قرارداد OIDC Authorization Code + PKCE مشاهده‌شده؛ ورود داخل WebView خود مفید انجام می‌شود و نام کاربری/رمز در اپ ذخیره نمی‌شود.
- نگهداری access token و شناسهٔ مشتق‌شدهٔ حساب در `flutter_secure_storage`، همراه زمان انقضای نشست.
- دریافت موجودی جاری از `/assetmodule/api/performance`، قدرت خرید گزارش‌شده از `/easy/api/money` و قیمت نمادها از `/symbols/api/marketdata`.
- قیمت برآورد فروش با اولویت بهترین سفارش خرید؛ در نبود آن، آخرین معامله و سپس قیمت پایانی با برچسب صریح استفاده می‌شود.
- نمایش حجم بهترین خریدار و هشدار در صورتی که از تعداد سهم نمایش‌داده‌شده کمتر باشد.
- ساخت، تغییر نام و حذف سبدهای محلی؛ تخصیص تعداد هر نماد بین سبدها؛ جلوگیری از تخصیص منفی یا بیش از موجودی؛ نمایش بخش تخصیص‌نیافته.
- داده‌های محلی به کلید حساب مفید scope می‌شوند تا دو حساب روی یک گوشی با هم مخلوط نشوند.
- حالت نمایش ارزش جاری به تومان یا «واحد معادل عیار» با ISIN عمومی `IRTKMOFD0001`.
- دیده‌بان محلی با جست‌وجوی فهرست نمادهای مفید، افزودن/حذف و refresh قیمت.
- snapshot عمومی TGJU برای دلار، یورو، سکه امامی، طلای ۱۸ عیار و حباب سکه. فقط دلار و طلای ۱۸ عیار، که واحد ریال آن‌ها در capture تأیید شده، در مرز data به تومان تبدیل می‌شوند؛ سایر اقلام با «واحد منبع» نمایش داده می‌شوند.
- خروجی امن Markdown از سبد انتخاب‌شده؛ توکن، رمز و شناسهٔ ورود وارد خروجی نمی‌شوند.
- اشتراک‌گذاری مستقیم روی شبکهٔ محلی بدون backend: گوشی مالک یک HTTP server سبک روی پورت `8787` اجرا می‌کند، snapshot خواندنی پرتفوی را با Basic Auth می‌دهد و گوشی بیننده با آدرس LAN + یوزر/پس وصل می‌شود. یوزر/پس عمداً داخل سورس ثابت است: `viewer / portfolio123`.
- GitHub Actions برای bootstrap پروژهٔ Android، codegen، format، analyze، test و ساخت APK دیباگ.

## مرزهای عمداً رعایت‌شده

این پروژه عدد مالی حدسی را به‌عنوان سود واقعی نمایش نمی‌دهد. گزارش سفارش موجود، وضعیت و `executedQuantity` تجمعی سفارش را می‌دهد و execution مستقل با شناسه/زمان/قیمت قطعی هر اجرا را اثبات نمی‌کند؛ بنابراین سود واقعی امروز/هفته/ماه سبدهای محلی و تخصیص خودکار تاریخی تا دریافت endpoint اجرای معاملات «دادهٔ کافی نداریم» باقی می‌ماند. همچنین `buyPowerT2` به‌عنوان «قدرت خرید گزارش‌شده» نشان داده می‌شود و با ارزش سهام جمع نمی‌شود، چون قدرت خرید الزاماً وجه نقد مالکانه نیست.

اشتراک‌گذاری این نسخه backend اختصاصی ندارد و روی LAN کار می‌کند. گوشی مالک باید اپ را باز نگه دارد و هر دو گوشی باید به یک شبکهٔ محلی دسترسی داشته باشند. برای مشاهده از اینترنت بدون قرارگرفتن در یک شبکه، هنوز به یک مسیر قابل‌دسترسی عمومی مثل backend/relay/VPN/port-forward نیاز است. حباب طلای ۱۸ عیار نیز از `coin_blubber` ساخته نمی‌شود؛ آن کلید حباب سکه امامی است.

## راه‌اندازی

این repository عمداً پوشهٔ generated Android را حمل نمی‌کند. در محیطی که Flutter stable نصب است:

```bash
./tool/bootstrap.sh
flutter run
```

اسکریپت `tool/bootstrap.sh` در صورت نبود `android/` آن را با شناسهٔ `com.mohamad72.portfolio` می‌سازد، مجوز اینترنت را اضافه می‌کند، cleartext HTTP را برای اتصال LAN فعال می‌کند، packageها را می‌گیرد و فایل‌های DI را تولید می‌کند.

برای verification کامل:

```bash
./tool/bootstrap.sh
dart format lib test
flutter analyze --no-fatal-infos
flutter test
flutter build apk --debug
```

جزئیات طراحی و قرارداد APIهای استخراج‌شده از captureهای کاربر در `docs/superpowers/specs/2026-09-11-portfolio-design.md` است. فایل‌های HAR خام، cookie، token و credential نباید وارد repository شوند.
